% Experience headings with a tech stack, the way \resumeProjectHeading does it.
%
% Why a new macro instead of just appending the stack to the company arg:
% \resumeSubheading puts the company bottom-left and the location bottom-right,
% so the company shares that row with the location. Measured against cmti10 at
% \small on this template's 405pt row, "Carnival Corporation (Princess Cruises)
% | Java, Spring Boot, Python, Azure OpenAI, Atlassian Rovo, Copilot Studio, MCP"
% + "Fort Lauderdale, FL" comes to 597pt -- it overflows by ~190pt and wraps.
% Projects get away with long stacks because they have no location column.
%
% So the location moves up beside the dates (that row has ~95pt of slack) and
% the company line owns the full width. Same four arguments in the same order as
% \resumeSubheading, so migrating is: rename the command, append the stack to #3.
% ─────────────────────────────────────────────────────────────────────────────
\newcommand{\resumeSubheadingStack}[4]{
  \vspace{-2pt}\item
    \begin{tabular*}{0.97\textwidth}[t]{l@{\extracolsep{\fill}}r}
      \textbf{#1} & \textbf{\small #4 $|$ #2} \\
      \textit{\small #3} & \\
    \end{tabular*}\vspace{-7pt}
}
